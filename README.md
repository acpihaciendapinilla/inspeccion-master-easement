# Inspección Master Easement

Checklist web para el recorrido de inspección Master Easement de Hacienda Pinilla. Se abre desde el celular, registra estado, comentario y fotos por ítem, guarda la hora de inicio y fin de cada sitio, y genera un PDF al terminar el recorrido.

- App: `index.html` (un solo archivo, sin instalación).
- Los sitios y los ítems se configuran al inicio del script, en `SITIOS` e `ITEMS_BASE`.
- Versión actual: ítems de ejemplo, pendiente la lista real de la ruta.
